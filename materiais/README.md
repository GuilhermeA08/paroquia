# Materiais da paróquia

Coloque aqui os arquivos originais que o site deve usar. Daqui eles são
tratados (redimensionados, convertidos e renomeados) e copiados para
`public/`, onde o site os publica. Esta pasta não é publicada.

## logo/

- O logo da paróquia, de preferência em **SVG**. Se não houver, um **PNG
  com fundo transparente** de pelo menos 1024 px.
- Versões alternativas, se existirem: colorida, branca, preta, só o símbolo.
- As cores oficiais (códigos hex), se a paróquia tiver um manual de marca.

## fotos/

- Fachada e interior da igreja, altar, celebrações, eventos, grupos.
- Use o nome do arquivo para dizer o que é a foto, por exemplo
  `fachada.jpg`, `festa-padroeira-2025-procissao.jpg`.
- Mande no maior tamanho que tiver. A foto que deve abrir o site pode
  ter `capa` no nome.

## textos/

- História da paróquia, nome do pároco, horários atualizados, endereço,
  telefone, chave Pix, avisos e notícias.
- Qualquer formato serve: `.txt`, `.md`, `.docx` ou `.pdf`.

## outros/

- QR Code do Pix, folhetos, cartazes e o que mais não couber acima.
